# Recursos visuales

Coloca aquí recursos propios o con licencia de uso para la tienda. Se sirven desde la raíz del sitio:

- `brand/`: logo principal y variantes. Ejemplo: `/media/brand/logo.svg`.
- `banners/`: imágenes del carrusel. Recomendado: `home-01.webp`, `home-02.webp`, `home-03.webp` (1920 × 700 px).
- `categories/`: iconos o miniaturas de categorías.
- `products/`: imágenes de producto. Recomendado: formato cuadrado de al menos 800 × 800 px.
- `payments/`: logos de medios de pago autorizados.

Los banners se configuran en `src/features/home/banner-slides.ts`. Las imágenes de productos provienen de la propiedad `imageUrl` de la API.
